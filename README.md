# Data Science Introduction

This repository contains the teaching notes I use for my introductory Data Science and Machine Learning classes. The material is intended for beginners and covers the fundamental concepts required to build machine learning models using Python.

## Prerequisites

To follow these notes, you should have a basic understanding of Python programming, a solid foundation in mathematics (including algebra, functions, statistics and probability) and a Python environment set up with the required packages installed.

## Scheme of Work

- 01 - Introduction to NumPy
- 02 - Introduction to Pandas
- 03 - Matplotlib Basics
- 04 - Seaborn Basics
- 05 - Data Visualization Fundamentals
- 06 - Basic Data Cleaning
- 07 - Correlation Analysis
- 08 - Introduction to Machine Learning
- 09 - Logistic Regression: Theory
- 10 - Logistic Regression: Example
- 11 - Feature Selection
- 12 - Linear Regression: Theory
- 13 - Linear Regression: Example
- 14 - Interpreting Linear Models
- 15 - Decision Trees: Theory
- 16 - Decision Trees: Examples
- 17 - Hyperparameter Tuning
- 18 - K-Means Clustering: Theory
- 19 - K-Means Clustering: Example
- 20 - Principal Component Analysis (PCA) Before Clustering

## Learning Outcomes

By the end of these notes, you should be able to:

- Manipulate and analyze data using NumPy and Pandas.
- Create effective data visualizations using Matplotlib and Seaborn.
- Clean and preprocess real-world datasets.
- Perform Exploratory Data Analysis (EDA).
- Build, evaluate, and interpret regression and classification models.
- Apply feature selection and hyperparameter tuning techniques to improve model performance.
- Perform clustering using the K-Means algorithm.
- Apply Principal Component Analysis (PCA) for dimensionality reduction before clustering.
